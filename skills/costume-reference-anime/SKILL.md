# 二次元服装参考

在 `references/catalog.csv` 中按中文名称、分类、英文关键词或 `charadb-Oxxx` ID 检索。数据从官方固定提交导入，图片不随仓库分发。完整来源说明见仓库根目录 `NOTICE.md`，来源版本见 `data/charadb/source.json`。

1. 默认提供1—3个候选的名称、ID、原始英文标签和来源链接，不随机混入现实服装。
2. 先告知使用者：CharaDB 图片仅供参考，禁止用于表现真实人物或未成年人，禁止原图或加工图再分发、转载和转售；图片不适用MIT/CC0，无需署名。远程展示及向模型传图未取得额外授权，不能认为热链自动允许。
3. 仅在使用者明确选择且确认用途符合作者条件后，才读取CSV内的精确原站图片URL作为参考，不改写任意远程地址，不批量下载、不保存镜像、不提交图片。向模型传图前说明会发送给使用者所选服务。
4. 不将这些图片用于真人换装或未成年人创作；无法确认合规用途时，仅用CC0标签并提供原站链接。参考图中人物的脸、发型、动作和背景不应当作服装要求。
5. 保持英文标签原文，按需求添加自有角色词条。`敏感=True`条目默认排除；仅成年使用者明确请求适当成人向素材时才纳入候选。此字段不是年龄或内容检测。

原站：https://charadb-2fi.pages.dev/ 。[官方许可](https://github.com/taki-ttt/charadb/blob/main/LICENSE)。离线仍可检索CSV与复制标签，图片及生成参考需来源在线；不擅自替换为第三方镜像。
